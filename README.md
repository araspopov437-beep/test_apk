# Shorts — Android-приложение

Приложение — это ваш `shorts__1111.html` (лежит в `app/src/main/assets/index.html`),
запущенный внутри Android WebView. Работает через интернет (Supabase).

Что настроено:
- камера, микрофон и запись видео (запрос разрешений при первом использовании);
- выбор файлов для загрузки видео, обложек и аватара;
- кнопка «назад» работает с внутренней навигацией приложения, выход двойным нажатием;
- ссылки и «поделиться» (например, ВК) открываются во внешних приложениях;
- автовоспроизведение видео, чёрная статус-панель, портретная ориентация.

Сборка APK: загрузите содержимое папки на GitHub — сборка запустится автоматически
(вкладка Actions), готовый APK будет в разделе Artifacts.

Чтобы обновить приложение, замените `app/src/main/assets/index.html` на новую версию файла.
