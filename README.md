# LiftLog — трекер тренировок (Android, Kotlin + Jetpack Compose)

Возможности:
- запись тренировки: упражнения, подходы (вес × повторения), название;
- подсказка «Прошлый раз» для каждого упражнения;
- общий таймер тренировки и таймер отдыха (60/90/120 с, звуковой сигнал);
- история тренировок с объёмом и длительностью, удаление;
- статистика: тренировки по неделям, объём, личные рекорды и оценка 1ПМ;
- локальное хранение (Room/SQLite), светлая/тёмная тема, Material You.

## Как собрать APK
1. Установите Android Studio (Koala 2024.1 или новее, JDK 17 идёт в комплекте).
2. File → Open → выберите папку `LiftLog`, дождитесь Gradle Sync
   (нужен интернет для загрузки зависимостей).
3. Тест: подключите телефон (отладка по USB) или создайте эмулятор и нажмите Run ▶.
4. Debug-APK: Build → Build Bundle(s) / APK(s) → Build APK(s).
   Файл: `app/build/outputs/apk/debug/app-debug.apk`.
5. Релизный APK: Build → Generate Signed Bundle / APK → APK, создайте ключ (keystore).

Сменить имя пакета: `applicationId` и `namespace` в `app/build.gradle.kts`.
